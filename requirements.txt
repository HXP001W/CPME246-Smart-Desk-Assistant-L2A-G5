Smart Desk Assistant — Development Environment Setup Reference
Overview
This document lists the required software environments, packages, project structure, and model files needed to reproduce the Smart Desk Assistant development setup so far.

The current scope covers:
	•	macOS development environment for computer vision prototyping
	•	Python virtual environment setup
	•	OpenCV camera testing
	•	MediaPipe Tasks API setup
	•	Downloaded model files for face, pose, and object detection
	•	Recommended folder structure for team collaboration
⸻
1. Current Development Platforms

Primary development machine
	•	macOS on Apple Silicon
	•	Visual Studio Code
	•	Terminal using zsh

Final deployment target
	•	Raspberry Pi 5
	•	Raspberry Pi OS
	•	Python 3.13.2 preferred

⸻

2. Python Version
Use Python 3.13.2.

Check version:
python3.13.2 --version

⸻

3. Virtual Environment Setup

From the project root:

python3.13.2 -m venv .venv
source .venv/bin/activate
python --version

Expected result:
	•	.venv is active
	•	Python version shows 3.13.2

⸻

4. Core Python Packages Installed So Far

Install with:

python -m pip install --upgrade pip setuptools wheel
python -m pip install opencv-python mediapipe numpy pillow matplotlib flask pandas

Package purposes
	•	opencv-python — camera access and image display
	•	mediapipe — vision tasks API and on-device ML inference
	•	numpy — numerical array processing
	•	pillow — optional image utilities
	•	matplotlib — optional plotting/debugging
	•	flask — future UI/dashboard backend
	•	pandas — future reporting/log processing

Notes
	•	tflite-runtime is not available on macOS and is not needed for current Mac testing
	•	tensorflow is optional at this stage and not required for the current MediaPipe Tasks workflow

⸻

5. Visual Studio Code Notes
Recommended interpreter
Select the virtual environment interpreter:
	•	.venv/bin/python

In VS Code:
	•	Command Palette → Python: Select Interpreter
	•	Choose the interpreter inside .venv

Optional .vscode/settings.json:

{
  "python.defaultInterpreterPath": "${workspaceFolder}/.venv/bin/python"
}

Important

Project files should not be stored inside .venv.

Correct structure:

smart-desk-assistant/
├── .venv/
├── models/
├── tests/
├── vision/
└── main.py


⸻

7. MediaPipe Version and API Choice

Current setup uses a newer MediaPipe version where the old mp.solutions API is no longer the correct path for this workflow.

Therefore, the project uses the MediaPipe Tasks API.

Current import style:

from mediapipe.tasks import python
from mediapipe.tasks.python import vision

This is the API style to use going forward.

⸻

8. Model Files Downloaded So Far

All model files are stored in the models/ folder.

Downloaded files
	•	blaze_face_short_range.tflite
	•	face_landmarker.task
	•	pose_landmarker_lite.task
	•	efficientdet_lite0.tflite

Purpose of each model
	•	blaze_face_short_range.tflite
	•	face detection
	•	confirms user presence in frame
	•	face_landmarker.task
	•	detailed face landmarks
	•	future use: head direction, attention cues, face orientation
	•	pose_landmarker_lite.task
	•	body/upper-body landmarks
	•	future use: posture and slouch detection
	•	efficientdet_lite0.tflite
	•	general object detection
	•	future use: phone detection

10. Testing Order Agreed So Far

Models should be tested one at a time in this order:
	1.	Face Detector
	•	model: blaze_face_short_range.tflite
	•	goal: verify MediaPipe Tasks pipeline + camera + detection
	2.	Pose Landmarker
	•	model: pose_landmarker_lite.task
	•	goal: verify posture landmarks for desk posture monitoring
	3.	Face Landmarker
	•	model: face_landmarker.task
	•	goal: verify stable face landmarks for attention tracking
	4.	Object Detector
	•	model: efficientdet_lite0.tflite
	•	goal: test phone detection
	5.	Combined logic later
	•	fuse outputs into a simple focused vs distracted state

⸻

11. Current Recommended Development Approach

Phase 1 — MacBook prototyping

Develop and test computer vision modules on macOS first:
	•	face presence
	•	face landmarks
	•	posture tracking
	•	object detection

Phase 2 — Combine outputs

Create simple rule-based logic such as:
	•	face missing → distracted
	•	looking away → distracted
	•	bad posture → warning
	•	phone visible → distracted

Phase 3 — Port to Raspberry Pi

After CV modules are stable on macOS:
	•	move code to Raspberry Pi 5
	•	replace or adapt camera handling if needed
	•	connect sensors, lighting, servo, and water/mister hardware

⸻
