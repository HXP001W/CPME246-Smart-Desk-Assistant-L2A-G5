Great — here’s a Raspberry Pi setup path tailored for this repo.

## 0) Use the right Pi image
Use **Raspberry Pi OS 64-bit (Bookworm)** on a Pi 4/5 (recommended).  
(ARM64 gives better wheel support for `opencv`, `mediapipe`, etc.)

## 1) Install system dependencies
On the Pi:

```bash
sudo apt update
sudo apt install -y \
  git python3 python3-venv python3-pip python3-dev \
  build-essential cmake pkg-config \
  libatlas-base-dev libopenblas-dev liblapack-dev gfortran \
  libjpeg-dev zlib1g-dev libpng-dev libtiff5-dev \
  libhdf5-dev libhdf5-serial-dev \
  libgl1 libglib2.0-0 v4l-utils libcamera-apps
```

## 2) Get the repo
```bash
git clone <YOUR_GITHUB_REPO_URL>
cd CPME246-Smart-Desk-Assistant-L2A-G5
```

## 3) Create and activate virtual environment
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip setuptools wheel
```

## 4) Install Python requirements (hardware-first)
Your repo has both `requirements.txt` and `requirements-hardware.txt`, so do:

```bash
pip install -r requirements-hardware.txt
pip install -r requirements.txt
```

If one fails, continue with the other and install missing packages individually.

## 5) Camera sanity check
```bash
libcamera-hello -t 3000
```
If this works, the Pi camera stack is fine.

## 6) Run a quick project test
From repo root (venv active):
```bash
python modules/face_recognition/testmain.py
```

---

## Important Pi note (DeepFace/TensorFlow)
`modules/deepface` may pull TensorFlow-heavy deps that can be difficult on Pi.  
If install fails there, run the project pieces that rely on MediaPipe/OpenCV first, then handle DeepFace separately.
